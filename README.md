# Skybound Flight Simulator

Een browser-flightsimulator met een bewegende landingsbaan, cockpitinstrumenten en eenvoudige vliegcontrols.

## Starten en opstijgen

1. Open `index.html` in je browser en vernieuw de pagina om de nieuwste versie te laden.
2. Zet **THROTTLE** op 80–100%. De baanstrepen bewegen nu naar je toe terwijl je over de startbaan rolt.
3. Als de snelheid boven 55 knopen is, zet **PITCH** op +7° om op te stijgen. Zodra je los bent van de grond verdwijnt de startbaan uit beeld.
4. Gebruik **HEADING** om de koers te veranderen. De zichtbare omgeving schuift mee.
5. Zet **PITCH** rond 0° om ongeveer horizontaal te vliegen; een negatieve pitch laat je dalen.

De besturing is een eenvoudige arcade-simulatie, geen realistische luchtvaarttraining.
