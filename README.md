# Havik — tweedekker simulator

Een arcade-vliegsimulator in een ouderwetse tweedekker.

## Opstijgen

1. Open `index.html` en vernieuw de pagina volledig.
2. Zet **GAS** op 80–100%.
3. Wacht tot de snelheid boven 48 knopen komt.
4. Zet **NEUS** op +6° of hoger.

## Sturen

Gebruik **KOERS** om werkelijk te draaien. Bergen, velden, weiden, bomen, baanstrepen en horizon draaien en bewegen als één landschap mee. De tweedekker blijft een eenvoudige arcade-simulator.
